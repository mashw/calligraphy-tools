# Movable Woven designs and native Layout elements

Standalone Woven stores optional `centerX`/`centerY` coordinates in page millimetres. Older version-1 files retain the original page-centred placement. Dragging the route moves its actual generated geometry; the camera is frozen at pointer-down and client coordinates are mapped through the captured inverse SVG matrix. A four-pixel threshold distinguishes a crossing click from movement. Alt-drag, middle-drag and background dragging retain the shared camera behavior. Cancelling a design drag restores its original position. X/Y fields and Centre on page provide precise placement.

Manual Simplify is transient preview state. Shape dragging, slider dragging and numeric dimension/rotation edits automatically show a lightweight, crossing-aware route with selection bounds. The shared `buildWovenRouteModel` calculates route, crossings, gaps and warnings without constructing dense grids/slants. Detailed geometry is restored at the end of the interaction. Standalone exports generate full scenes independently of preview mode.

Layout's native `woven` element stores generation settings and crossing overrides. Its existing frame supplies route dimensions/placement in millimetres, and its existing rotation supplies the element transform. The settings omit standalone page/camera fields. Both editors share `buildWovenModel`, `buildWovenRouteModel` and the complete writing/crossing inspector. Copperplate retains its fixed 1 mm unit. Layout excludes the standalone title and calibration ruler, keeps transparent whitespace, and supports its normal layer, lock, visibility, duplicate, alignment, resize and rotation actions. Corner resizing preserves the current proportions. Guide bands may extend beyond the route frame, as they do around an equivalently sized standalone route.

During Layout pointer operations, full-detail geometry remains cached at the committed frame while the lightweight route follows the live frame. Numeric/slider edits similarly retain an initial detail snapshot until the edit ends. The export clone restores full-detail subtrees and removes preview/selection geometry, including when manual Simplify remains enabled.

SVG and Print use the full vector scene with physical page dimensions. Cricut Draw consumes the same procedural centreline polylines, then uses Layout's existing transforms, page clipping, higher-layer occlusion, safety checks and combined/separate-layer serialization. Construction/slant export options apply to Woven too. Woven's transparent whitespace does not mask lower elements.

Woven-only Layout PDFs are entirely vector. Mixed PDFs interleave Woven vector strokes/text with transparent images of the existing non-Woven layers, preserving their original rendering and stacking. Non-Woven elements retain Layout's existing raster PDF behavior; they have not been converted to a new mathematical definition. This also preserves masks, reserved regions and artwork compositing around Woven. Print now uses a full-size SVG document instead of rasterizing Woven.

Validation includes 146 unit tests, all existing browser tests and five new browser scenarios at 390/1440 px. New checks cover movement without panning, panning without movement, zoom accuracy, crossing clicks, transient/manual Simplify, exact preview/export guide paths, frame resize/rotation handles, frozen detail during resize, duplication/reordering/locking/visibility, standalone/Layout Save/Open, SVG/PDF/Print/Cricut output, physical PDF dimensions and absence of raster images in a Woven-only PDF. Browser tests inspect the actual generated export Blobs because this host may cancel operating-system downloads. Physical printer/Cricut hardware output remains a manual check.
